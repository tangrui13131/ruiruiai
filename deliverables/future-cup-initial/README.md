## 建议使用

1. 先阅读“文案/初赛方案书.docx”。
2. PPT 制作优先使用“架构图/”和“测试截图/”。
3. 赛题评审使用“文案/赛题证据矩阵.md”或“测试截图/04-赛题证据矩阵.png”。
4. 方案书转 PDF 时保持图片相对路径和字体设置。
