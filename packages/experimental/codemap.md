# packages/experimental/

## Responsibility
Evaluated capabilities and competition platform prototypes outside standard harness core.

## Design
Incubation workspace for the Future Cup browser platform, orchestration engine, MCP Server surface, and specialized testbeds.

## Flow
Future Cup platform and orchestration components collaborate to deliver end-to-end frontend generation; external MCP clients enter through the platform server.

## Integration
Composed into Cordis profiles via cordis.patch.yml or dedicated launch configurations, exposing browser and loopback MCP consumers.
